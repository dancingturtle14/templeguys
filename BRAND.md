# SanctaWay brand guidelines

**Positioning:** A quiet pilgrimage atlas — visit guides for temples, churches, mosques, shrines, and sacred places worldwide. Religion-neutral. Practical first. Respectful always.

**Domain:** sanctaway.com (GitHub Pages custom domain).

## Voice

| Attribute | Means | Avoid |
| --- | --- | --- |
| Clear | Hours, dress, routes in plain English | Mystical fluff, filler |
| Respectful | Living worship; verify locally | Speaking for any faith |
| Editorial | Guidebook tone, calm confidence | Startup hype, emoji |
| Inclusive | “Sacred places,” “shrines,” “houses of worship” | Temple-only framing |

**Example:** “Cover shoulders and knees. Ask before photographing people at prayer.”  
**Not:** “Unlock divine vibes on your sacred journey ✨”

## Color

| Token | Hex | Role |
| --- | --- | --- |
| `paper` | `#F3EEE4` | Page ground |
| `paper-deep` | `#E7E0D2` | Bands, panels |
| `stone` | `#D4CBBA` | Rules, placeholders |
| `ink` | `#1A1814` | Primary text / dark UI |
| `ink-soft` | `#3F3A34` | Body secondary |
| `ink-muted` | `#6F675C` | Meta / captions |
| `cinnabar` | `#9C3B2E` | Single accent (labels, active, links) |
| `cinnabar-wash` | `#F0E4DF` | Soft accent panels |
| `line` | `#C9BFAE` | Hairline borders |

One accent per view. No purple, no neon gold, no multicolor gradients on chrome.

## Typography

| Role | Face | Notes |
| --- | --- | --- |
| Display | **Cormorant Garamond** | Titles, wordmark, section heads |
| Body / UI | **Public Sans** | Nav, body, forms, captions |

- Headings: `text-balance`
- Body: `text-pretty`
- No custom letter-spacing
- Tabular nums for counts and facts

## Imagery

- Full-bleed or sharp-cropped photography; warm stone fallback if load fails
- Prefer quiet atmospheres over tourist selfies
- Credit photographers on detail pages
- Prototype uses Unsplash URLs — replace before production

## Logo / wordmark

- Wordmark only: **SanctaWay** in Cormorant, medium weight
- No temple-icon-in-rounded-square
- Optional thin horizontal rule under masthead

## Layout principles (from Threshold Atlas)

- Asymmetric / magazine layouts over equal three-card grids
- Hairline borders; minimal or no card shadow
- Solid paper header (no glass blur)
- Soft footer link to hktemplegifts.com only — no hard sell in guides

## Tone matrix

| Context | Tone |
| --- | --- |
| Home | Inviting, atlas-like, brief |
| Directory | Utilitarian, scannable |
| Visit guide | Practical, caution where needed |
| About | Humble, clarify verify-before-visit |
| Empty / 404 | Calm, one clear next action |
