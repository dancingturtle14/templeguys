徒歩

伏見稲荷を歩く

六つの立ち寄りを、一画面ずつ進むステップ式で — 稲荷駅から四ツ辻まで。ルートマップに従うか、Google マップで徒歩の道順を開いてください。山頂一周は、開くまで閉じたままです。

ここに記載の時間は一般的な参拝者の目安であり、神社が掲示した時刻表ではありません。社務所の時間は掲示板または inari.jp でご確認ください。 inari.jp.

第 01 番

駅から楼門まで

楼門、そして手水舎。

JR 奈良線の各駅停車は稲荷駅に停まり、京都駅の南へ 2 駅です。

快速の多くは稲荷駅を通過するので、乗る前にホームの電光掲示を読んでから、数分かけて上りへ神社へ向かいましょう。

朱色の楼門（Romon）、つまり正面の門を通り抜け、社殿の前に進む前に手を清める手水舎（temizuya）の水盤を目にします。

境内と山道に入場料はかかりません。

  • JR 稲荷駅
  • 各駅停車
  • 楼門
  • 手水舎
  • 境内は無料

見どころsee · JR 稲荷駅

see · JR 稲荷駅

JR 奈良線の各駅停車に乗ってください。稲荷駅は京都駅の南へ 2 駅で、多くの快速はここを通過します。

改札を出れば、神社は上りへ短い道のりです。人の流れと、前方に見える朱色を目印に歩きましょう。

注目ポイント

  • ホームでは、乗る前に電車の種別を確認しましょう。各駅停車は稲荷駅に停まります。快速の多くは停まりません。
  • 神社の方向へ歩き出しましょう。バスではなく、上りへ数分の徒歩です。
  • この通りには屋台が並びます。お腹が空いていたらここで食べましょう。山道では歩きながらの飲食が制限されています。
見どころsee · 楼門（正面の門）

see · 楼門（正面の門）

楼門は境内の入口にある二層の門です。チケット売り場の周りを回るのではなく、この門をくぐって進みます。

神社の記録はこの門を 1589 年の建立とし、寄進は豊臣秀吉によるものと伝えています。それでも、この門の先に拝観料はかかりません。

注目ポイント

  • 参道の中央に立って、門が社殿を枠取りする瞬間だけを長くしすぎず、撮影したら脇へ寄りましょう。
  • 見上げてください：二層の朱色。上層は門の一部であって、登るためのデッキではありません。
  • 門に切符売り場はありません。ただ通り抜けるだけです。
対象狐の手水舎

狐の手水舎

内側すぐにある手水舎は水盤で、ここでは狐の形をしています。先に進む前に手を清めるためのもので、飲むための噴水ではありません。

神社のいつもの順序は、左手、右手、口、そして柄杓の柄です。掲示に別の順序が示されている場合は、掲示に従ってください。

注目ポイント

  • そのいつもの順序では、柄杓を右手に持って：左手、右手、口、そして柄。
  • 水を飲まないこと、そして柄杓に口をつけないこと。
  • 狐は水盤の形です。水はあくまで清めのためだけのものです。
言い伝え参道の揚げ豆腐

参道の揚げ豆腐

言い伝えでは、狐は揚げ豆腐を好むとされ、だからこそ稲荷寿司 — 豆腐の袋 — が、駅と門の間の店に並びます。

これは民俗的な説明であって、儀式ではありません。屋台は普通の食べ物です。ここで食べるか、山道を下りてから食べるかで、歩きながら食べないようにしましょう。

第 02 番

密集するトンネル

下段の山道に連なる奉納の朱色の鳥居。

本殿の裏で、道は千本鳥居（Senbon Torii）に入ります。企業や参拝者が奉納した、二本の近接した鳥居のトンネルです。

密集した区間は、歩いて 10〜15 分ほどになることが多く、写真を撮る人が立ち止まると長くなります。

鳥居は狭いので、脇に寄って歩き続け、他の人が通れるようにしましょう。

柱の名は寄進者を記しています。鳥居は奉納であって、登るものではありません。

  • 二本のトンネル
  • 約 10–15 分
  • 歩き続ける
  • 奉納された鳥居

見どころsee · 二本の近接したトンネル

see · 二本の近接したトンネル

本殿の裏で、道は二本の平行した鳥居の回廊に分かれ、その近さゆえにずっと木陰の中を歩くことになります。

密集した区間は歩いて 10〜15 分ほど。写真のために立ち止まるなら、回廊が流れ続けるよう端に寄りましょう。

注目ポイント

  • 二本の回廊は並んで走っています。片方を歩き、両方味わいたいなら、もう片方も。
  • 立ち止まるなら端に。中央が歩く人の線です。
  • 振り返ってみてください：鳥居がトンネル状に積み重なっています。前方では、鳥居が登りへと開けていきます。
対象なぜ千本と呼ぶのか

なぜ千本と呼ぶのか

千本とは「千の鳥居」という意味です。この名が定着しました。山にあるのは千をはるかに超え、覚えておくべき掲示された数などありません。

密集したトンネルを過ぎると、鳥居はまばらになり、道は鳥居の下を歩くというより、鳥居の間を縫う登りへと変わります。

対象柱に書かれた文字

柱に書かれた文字

朱色の柱の黒い文字は、寄進者と、たいていの場合その年号を記しています。多くの寄進者は、名もなき巡礼者ではなく企業や職人集団です。

通り過ぎながら読んでみてください。あれは奉納の記録であって、登ったり何かを掛けたりするための背景ではありません。

注目ポイント

  • 鳥居の脇に立ち、下り方向を振り返って見える柱を読んでみましょう。
  • 名前、しばしば企業名、そして年号を期待してください。値段でも、唱えねばならない祈りでもありません。
  • 文字は朱色の中に刻まれています。奉納物を示しているのです。
柱には何が読めるでしょうか。
すべての読み方を表示
  • 企業名と年号. はい。多くの刻印は事業者や団体の名と年号です。それが寄進者の記録です。
  • 拝観料. いいえ。文字は料金ではありません。境内に入場料はありません。
  • 唱えるべき祈り. 参拝者が唱えるべき決まった祈りはそこに印刷されていません。文字は誰が鳥居を奉納したかを記すものです。
言い伝え繁栄を願って奉納された鳥居

繁栄を願って奉納された鳥居

伝えられるところでは、稲荷は米と結びつき、そこから商いへとつながります。事業者は鳥居を奉納し、木に名を刻みます。

その奉納こそが実践です。商いが良くなることを保証するものではなく、神社はこの回廊を有料のトンネルとして売ってもいません。

第 03 番

狐、石、そして分かれ道

登りに沿う神使と奉納の石。

石の狐が、稲荷の神使として登りに沿って立っています。口には鍵や宝珠をくわえていることも。

小さな お塚（otsuka）の集まりは、私的な奉納の石であって、あなたが完成させるべき一つの祭壇ではありません。

道が分かれるところでは、表示された道をたどり、木の間を近道して横切らないでください。

誰かが祈っているなら、声を落とし、場所を譲りましょう。

  • 狐（きつね）
  • お塚
  • 表示のある分岐
  • 祈りの近くは静かに

見どころsee · 石の狐

see · 石の狐

狐は稲荷の神使であって、稲荷そのものではありません。像は登りに沿って立ち、口にはしばしば鍵、宝珠、あるいは巻物があります。

鍵は一般的に、米の蔵の鍵と読まれます。それが物のいつもの説明です。すべての像に説明があるわけではありません。

注目ポイント

  • 像の隣に立って、像と、祈りを捧げている人の間に立たないようにしましょう。
  • 口を見てください：鍵、宝珠、あるいは巻物。口が空っぽだったり、摩耗してなめらかだったりする像もあります。
  • 狐の赤い前掛けは、参拝者が結んだものです。ほどかずにそのままに。
この狐は何をくわえているでしょうか。
すべての読み方を表示
  • 鍵. しばしば。いつもの読みは米の蔵の鍵です。図ではなく、目の前の像を確かめてください。
  • 宝珠または巻物. これもよくあります。口は一つの物だけをくわえ、決まった一式ではありません。宝珠でも巻物でも、同じ神使が違う装いで現れているのです。
  • 何も見えない. 口が空だったり、摩耗していることもあります。蔵の読みは、まだ鍵をくわえている像に属します。
対象お塚の石

お塚の石

お塚は、個人、家族、あるいは団体が奉納し、名を刻んだ私的な奉納の石です。何百と集まっています。

あなたが完成させるべき一つの祭壇ではありません。誰かが祈っているなら立ち止まり、列を腰掛けの壁のように扱わないでください。

見どころsee · 道が分かれるところ

see · 道が分かれるところ

脇道は小さな祠や、さらに多くの石へと分かれていきます。通り道は、四ツ辻へ戻る表示された道です。

切り返し地点へ戻るために、木の間を近道して横切らないでください。地面は根とゆるい石で、近道は人が迷う原因です。

注目ポイント

  • 分かれ道では、木の間ではなく、四ツ辻へ向かう表示された道をたどりましょう。
  • 鳥居がトンネルから間隔の空いた柱へと開けていたら、密集した千本鳥居の区間は過ぎています。
  • 細い脇道はたいてい、さらに石か小さな祠で行き止まりです。
言い伝え白い狐

白い狐

言い伝えでは、狐は稲荷に仕え、白い狐は像がたいてい取る姿です。狐が好むとされるので、人々は揚げ豆腐を供えます。

祈るのは稲荷に対して、社殿で。像は神使の姿であって、独自の儀式を持つ別の神ではありません。

第 04 番

現実的な折り返し地点

四ツ辻の分岐と、京都南部を見渡す眺め。

四ツ辻（Yotsutsuji）は稲荷山の途中にある十字路で、初めての参拝の多くにとって必要な折り返し地点です。

下段の鳥居から上りは、速さと混雑次第でふつう 30〜45 分かかります。

この分岐は京都南部を見渡します。普通の日は、休んで飲み物を買える小さな場所があります — それより上に同じ設備があると当てにしないでください。

時間が短い、あるいはでこぼこの階段に不安があるなら、ここでやめましょう。その先の道は、また別の外出です。

  • 上り約 30–45 分
  • 眺望
  • ここで折り返す
  • 休憩所

見どころsee · 四ツ辻の分岐

see · 四ツ辻の分岐

四ツ辻は文字どおり四方の十字路を意味します。道は下段の鳥居から来て、上の社へ続いています。

密集したトンネルからは、ふつう 30〜45 分の登りで、混んでいるともっとかかります。

注目ポイント

  • 分岐の真ん中で止まり、道を数えてみましょう。名は四方の道を意味します。
  • 下る道は、登ってきた道です。進む道は、上の社へ向かう表示があります。
  • あなたは一本の hall の中にいるのではなく、道の交わる地点にいます。
見どころsee · 縁から見る京都

see · 縁から見る京都

この分岐は京都の南を見渡します。澄んだ日には、街が朱色と木々の下に広がります。

それは眺望であって、どこにでも手すりのある展望台ではありません。縁では足元に注意してください。

注目ポイント

  • 街を見渡すには、森の登りから離れた開けた側を向きましょう。
  • 人が通るときは縁から一歩下がって。どこにでも手すりがあるわけではありません。
  • 見どころはこの眺めです。屋台はrest であって、見どころではありません。
対象最後の楽な休憩

最後の楽な休憩

小さな休憩の屋台と飲料自販機は、ふつうこの分岐にあります。その先へ進むと、同じ設備があると当てにしないでください。

水を持っているなら、ここで補給を。上の一周は、眺めから受ける印象より長い道のりです。

言い伝え稲荷山、そして折り返し

稲荷山、そして折り返し

山は約 233 メートルです。この道は、有名なトンネルを含む巡礼の登りであって、山が付いているトンネルではありません。

初めての参拝の多くは、この十字路で完成します。進むのは選択であって、散歩の必須の終点ではありません。

四ツ辻でのあなたの選択

どちらを選んでも、参拝は完成します。引き返せば森の一周を省略し、進めば山頂一周が開きます。

第 05 番 · 任意山頂一周開くまで閉じています。

第 05 番

四ツ辻の先へ

森、小さな社、そして奥宮。

四ツ辻を過ぎると、道は上の社を巡る森のハイキングになり、その中には奥宮（Okumiya / Okunomiya）、内側の聖域があります。

一周するには、休憩を含めて 2〜3 時間ほどかかり、さらに密集した鳥居のトンネルではなく、根と石段を歩く道です。

水を持参し、日没後もまだ山にいる可能性があれば灯りを持ってください。

上の道は静かで、それでも働いている神社の一部です。表示された道を外れないでください。

  • 任意
  • 約 2–3 時間
  • 足場の悪い森
  • 灯りを持参

見どころsee · 奥宮（内側の社）

see · 奥宮（内側の社）

奥宮（Okumiya、Okunomiya とも表記）は、上の山にある内側の聖域で、四ツ辻の折り返し地点の先にあります。

トンネルより静かで、今も祈りの場所です。同じ道のルールが当てはまります。

注目ポイント

  • 社殿は下段の聖域より小さい。人が祈っているなら、祈りの空間には入らないでください。
  • オモカル石は近くにあり、台座の上にあります。社殿の中でも、道ばたの石でもありません。
  • 持ち上げるならまず願い事をし、同じ台座に戻しましょう。
言い伝えオモカル石

オモカル石

内側の社の近くの言い伝え：願い事をし、石を持ち上げます。思ったより軽く感じれば、願いが聞き届けられると言われ、重ければ、あまり良くないとされます。

それはこの場所の習わしであって、神社が保証する結果ではありません。脚で持ち上げ、石は見つけたときと同じように戻してください。

注目ポイント

  • 内側の社の近く、台座の上にある石を見つけましょう。道ばたの石を適当に拾わないこと。
  • 掲示された重さはありません。持ち上げた感覚と、自分が期待した重さを比べるのです。
  • 歩き出す前に、同じ台座へ戻してください。
願い事のあと、石はどんなふうに感じましたか。
すべての読み方を表示
  • 思ったより軽かった. 言い伝えでは、軽く上がれば願いが叶うとされます。神社が結果を保証するわけではありません。
  • 思ったより重かった. 言い伝えでは、重く感じるのはあまり良くない読みとされます。それでも、あくまで習わしです。
対象トンネルではなく森

トンネルではなく森

四ツ辻の先では、鳥居はまばらになり、小さな社、根、石段が巡る森の一周へと変わります。一周には休憩を含めて 2〜3 時間ほどかかります。

水を持参してください。日没後にまだ下っている可能性があれば、灯りを持ってください。山に街灯はありません。

対象複数の峰、一つの一周

複数の峰、一つの一周

上の道は、神聖な山の社を巡る一周であって、一つの眺めの山頂の台ではありません。

表示された一周から外れないでください。脇道は近道に見えて、穏やかなハイキングを捜索に変えてしまうものです。

第 06 番

下山、そして社務所へ

窓口が閉まっても、道は開いています。

登ってきた道を下るか、表示された一周をたどって本殿と駅のほうへ戻りましょう。

山道は社務所と同じ時計では動いていません。お守り、絵馬、御朱印は、道がまだ歩ける時間でも、日中の窓口のサービスです。

切符やお守りを当てにする前に、社務所に掲示された時間を読むか、inari.jp で確認してください。

飲食と行儀についてのルールは、エチケットの章にあります。京都へ戻る電車は、アクセスの章にあります。

見どころsee · 下りの二通り

see · 下りの二通り

登ってきた道を逆にたどるか、表示された一周をたどって本殿と駅のほうへ戻れます。

どちらも、別の出口の門ではなく、境内に着きます。乗りたい電車だけでなく、歩くこと自体に時間を残しましょう。

注目ポイント

  • 掲示は、来た道へ戻る方向と、一周する方向の両方を指しています。どちらも本殿に戻ります。
  • 山に二つ目の駅の出口はありません。境内で終わり、そこから電車へ下ります。
  • 灯りがないなら、下りに明るさを残しましょう。
対象絵馬（願いの札）

絵馬（願いの札）

絵馬は小さな木の札です。稲荷ではしばしば狐の形をしています。願い事を書き、係員が示す場所に札を掛けます。

窓口で販売しており、その窓口は日中の時間です。掛け桁が閉まっても、道はまだ開いていることがあります。

注目ポイント

  • ここの札は多くが狐の形、狐の顔で、長方形ばかりではありません。
  • 書いてから、係員が指す掛け桁に掛けましょう。他の人の札はそのままに。
  • 掛け桁は窓口と同じ時間で閉まります。道は同じ時計を使いません。
対象お守りと御朱印の窓口

お守りと御朱印の窓口

お守りと御朱印の帳面は窓口のサービスであって、道のサービスではありません。どちらを当てにする前に、掲示の時間を読むか、inari.jp で確認してください。

駅の外で「入場券」を売っている人のことは無視してください。境内に入場料はかかりません。

注目ポイント

  • お守りは、棚に並ぶ小さな錦の袋で、札に書かれた願い事ごとにまとまっています。値段は棚にあり、この案内にはありません。
  • 御朱印は判子の窓口と帳面で、袋と同じ棚ではありません。
  • 札が日本語だけなら、尋ねてください。布の色で、お守りの用途を推測しないこと。
決まり食事ができる場所

食事ができる場所

神社の行儀のルールは、道を歩きながらの飲食を制限しています。四ツ辻の休憩所で軽く食べることは、トンネルの中で食べるのとは違います。

行儀のルールはエチケットの章に一覧があります。京都駅へ戻る電車は、アクセスの章で扱っています。

End

散策の終わり

下段の鳥居と四ツ辻だけでも、ほとんどの人にとって十分な参拝です。山頂一周はまた別の朝に取っておけます。
